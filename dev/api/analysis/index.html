Analysis of correlations among metrics

DominguezGarcia2019.SizeCorrelations — Type
SizeCorrelations

Per-size correlation structure of a metrics table: for each richness in sizes, the Spearman correlation matrix rho, the covariance of ranks rankcov and the covariance of mean/range-normalised values valuecov of the metrics in labels (arrays are metrics × metrics × sizes), and the number of communities n used at each size.

source
DominguezGarcia2019.size_correlations — Function
size_correlations(df; labels = METRICS, sizes = 5:99, max_sample = 100, rng = Random.default_rng())

Correlations among the metrics labels of a table such as prepare_metrics returns, separately for the communities of each richness N in sizes, as in the authors' get_full_correlation_bysize (window width 0). At most max_sample communities per size are used, drawn with rng when there are more. The authors' loop covers N = 5–99.

source
DominguezGarcia2019.class_average — Function
class_average(sc::SizeCorrelations, lo, hi; field = :rho)

The element-wise mean and standard deviation over the sizes lo:hi (inclusive) of one of the per-size matrices (:rho, :rankcov or :valuecov), as the authors' get_av_corr_from_sdf and get_av_cov_from_sdf compute for the size classes small (5–15), medium (45–55) and large (85–95). Like pandas' mean() and std() there, undefined values (NaN, for a metric that is constant at some size) are skipped; an entry undefined at every size stays NaN.

DominguezGarcia2019.SIZE_CLASSES — Constant
SIZE_CLASSES

The three size classes of the paper, as name => (lo, hi) in the authors' processing order.

DominguezGarcia2019.metric_network — Function
metric_network(R)

The weighted, unsigned network of metrics from a matrix of mean correlations R: edge weights |Rᵢⱼ| (the absolute value of the averaged correlation, as in the authors' code), no self-loops. An undefined correlation (NaN) gives no edge, as the authors' threshold test abs(mean) > threshold is false for NaN.

DominguezGarcia2019.modularity — Function
modularity(W, groups; resolution = 1.0)

Newman's modularity of the partition groups (one label per node) of the weighted undirected network W.

DominguezGarcia2019.modular_groups — Function
modular_groups(W; runs = 10, resolution = 1.0, rng = Random.default_rng())

Groups of nodes of the weighted network W that maximise modularity, by the Louvain method, keeping the best of runs randomised runs (the paper ran Gephi's implementation ten times). Returns (groups, Q), with groups numbered 1, 2, … in order of first appearance.

DominguezGarcia2019.cophenetic — Function
cophenetic(h::Hclust)

The matrix of cophenetic distances of a hierarchical clustering: for each pair of leaves, the height at which they are first merged.

source
DominguezGarcia2019.metric_dendrogram — Function
metric_dendrogram(R; distance = :profiles)

Average-linkage hierarchical clustering of the metrics from their mean correlation matrix R. distance = :profiles follows the authors' code: rows of |R| are treated as correlation profiles and compared by correlation distance (SciPy metric='correlation'). distance = :one_minus_rho follows the paper's text, d = 1 − ρ. Returns the Hclust and the cophenetic correlation against both the clustering distance and, as the authors' code computes it, the Euclidean distance between |R| profiles: (tree, c_clustering, c_code).

source
DominguezGarcia2019.explained_variance — Function
explained_variance(Σ)

For each variable of the covariance matrix Σ, the share of the total variance it explains through its covariances, Σⱼ Σⱼᵢ² / (tr(Σ) Σᵢᵢ) (the authors' get_exp_var_ind), and its own share Σᵢᵢ / tr(Σ), as (exp_var, simple).

source
DominguezGarcia2019.ellipsoid_volume — Function
ellipsoid_volume(Σ)

The volume of the covariance ellipsoid of Σ after scaling its eigenvalues to sum to one, as in the authors' calculate_HV_covellipsoid: the unit-ball volume times the product of the square roots of the scaled eigenvalues. Isotropic covariance gives the largest value (0.8061 in three dimensions).

source
DominguezGarcia2019.correlation_types — Function
correlation_types(sc::SizeCorrelations; threshold = 0.1)

The classification of each metric pair by how its correlation changes with community size (SI §1, Fig. S1), with the authors' size windows: small 5–14 and 5–15, medium 50–59 (the code's positional slice; 45–55 for the sign test), large 85–95. Returns a DataFrame with columns a, b and type, the panel letter "A" to "G" (G: unchanged), or "-" if unassigned.
