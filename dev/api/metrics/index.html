Stability metrics

From the Jacobian

EcologicalResilience.reactivity — Function
reactivity(J)

Maximal instantaneous amplification rate of a pulse, λ_max((J + Jᵀ)/2) (Neubert & Caswell 1997). Positive values mean a reactive equilibrium. The dataset's raw R0 column holds this value; SI eq. 6 writes its negative, which the analysis applies later.

source
EcologicalResilience.resilience — Function
resilience(J)

Asymptotic return rate −Re λ_dom(J) (SI eq. 10); positive for a stable equilibrium.

source
EcologicalResilience.amplification_envelope — Function
amplification_envelope(J, t; p = 2)

A(t) = ‖exp(J t)‖ₚ, the operator p-norm of the propagator (SI eq. 7). With p = 2 it is the largest amplification at time t of any pulse; p = Inf (the maximum absolute row sum) is the norm behind the published Amax (see community_record).

source
EcologicalResilience.max_amplification — Function
max_amplification(J; dt = 0.1, tcap = 1e4, p = 2)

The maximum of the amplification envelope (amplification_envelope, operator p-norm) and the time at which it occurs, (Amax, tmax) (SI eqs. 8–9), on a time grid of step dt (the dataset's tmax values are multiples of 0.1). A non-reactive equilibrium (R0 ≤ 0) gives (1.0, 0.0) for every p, as in the published data, where Amax = 1 exactly when R0 ≤ 0. Otherwise the grid is followed until the envelope falls back below 1, or to tcap.

source
EcologicalResilience.pulse_covariance — Function
pulse_covariance(B)

The covariance of pulse perturbations proportional to equilibrium biomasses, Diagonal(B.^2), the choice of Domínguez-García et al. (2019) following Arnoldi et al. (2018).

source
EcologicalResilience.median_reactivity — Function
median_reactivity(J, C)

The median initial rate of displacement, Tr(C J)/Tr(C) for perturbation covariance C (SI eq. 11; Arnoldi et al. 2018).

source
EcologicalResilience.median_displacement — Function
median_displacement(J, C, t)

The median displacement at time t relative to its initial value, sqrt(Tr(C exp(Jᵀt) exp(Jt)) / Tr(C)) (SI eq. 12, as a norm ratio).

source
EcologicalResilience.median_max_amplification — Function
median_max_amplification(J, C; dt = 0.1, threshold = 0.005, tcap = 1e4)

(MAmax, Mtmax): the maximum over a grid of step dt of the median_displacement and the time it is reached, or (1.0, 0.0) if the displacement never exceeds its initial value. The scan runs until the displacement falls below threshold (the SI's asymptotic criterion, as in median_resilience) or t > tcap. It does not stop when the displacement first falls: a median displacement can shrink at first and grow later, even when the median reactivity is negative.

source
EcologicalResilience.median_resilience — Function
median_resilience(J, C; threshold = 0.005, dt = 0.1)

The median return rate −ln(Tr(C exp(Jᵀt) exp(Jt))/Tr(C)) / (2t) (SI eq. 13), evaluated at the first time t on a grid of step dt at which the median_displacement is below threshold (SI: "the asymptotic limit is reached if the displacement is below 0.005"). The time is found by doubling and then bisection on the grid. Returns NaN for an unstable J.

source
EcologicalResilience.stochastic_invariability — Function
stochastic_invariability(J; dense_max = 30, tol = 1e-10, maxiter = 2000)

Intrinsic stochastic invariability Is = 1 / (2 ‖Ĵ⁻¹‖₂) with Ĵ = J ⊗ I + I ⊗ J (SI eq. 14; Arnoldi et al. 2016). For size(J, 1) ≤ dense_max the Kronecker sum is formed and its smallest singular value computed directly. Otherwise ‖Ĵ⁻¹‖₂ is found by power iteration on Ĵ⁻ᵀĴ⁻¹, each product a pair of Sylvester solves (Ĵ vec X = vec(JX + XJᵀ)), so memory stays O(N²).

source
EcologicalResilience.sensitivity_matrix — Function
sensitivity_matrix(J)

The sensitivity matrix −J⁻¹: the equilibrium response of every species to a small sustained press on each (Bender et al. 1984).

source

press_sensitivity(J)

Community sensitivity S = Σᵢ |Σⱼ sᵢⱼ| of the sensitivity matrix (SI eq. 15); the raw column L1DBRMt_s.

EcologicalResilience.total_sensitivity — Function
total_sensitivity(J)

Σᵢⱼ |sᵢⱼ|, the raw column absumS. SI eq. 16's mean element strength <sᵢⱼ> divides it by N², which prepare_metrics does.

From simulated press perturbations

The experiments PerturbationOptions, global_mortality_tolerance, local_mortality_tolerances, press_response, removal_responses and extinction_tolerance are defined in ResilienceCore.jl and re-exported here. They run on any community that implements ResilienceCore's interface (state, present_species, with_mortality, without_species, jacobian), such as the assembled communities of FoodWebDynamics.jl.

Datasets

EcologicalResilience.RAW_COLUMNS — Constant
RAW_COLUMNS

The 39 data columns of the raw Dataset S1/S2 (after the network identifier), in file order: 28 metric columns, then N, iniN, Nb, Napex, Ncan, Btot, B_IPR and the community's exponents a_i, a_j, h_i, h_j.

EcologicalResilience.METRICS — Constant
METRICS

The labels of the 27 stability metrics, in the order of measures in the authors' code.

source
EcologicalResilience.community_record — Function
community_record([rng], c::Community; options = PerturbationOptions(), dt = 0.1,
                 convention = :published)

All raw columns of Dataset S1 (RAW_COLUMNS) for one assembled community, as a NamedTuple. This runs every perturbation experiment, so it is the expensive step. convention selects how Amax, tmax and the four median metrics are computed (see amplification_metrics). :published reproduces Dataset S1, and :si follows the SI's definitions.

The global press (RM_p, L1DBRM_p) raises every species' mortality by options.press, as the local presses do. Ranked within each richness, the published RM_p agrees with the sum of the local responses (Spearman ρ ≈ 0.92), as this definition does, but its values are about 30 times larger. No stronger press tried (mortality ×2–×11, plant carrying capacity, all loss terms) reproduces both the size and the ranking. The scale does not affect the paper's rank-based analyses.

The simulation experiments are those of ResilienceCore (global_mortality_tolerance, press_response, removal_responses, extinction_tolerance, …), run through FoodWebDynamics' implementation of the community interface. Requires using FoodWebDynamics.

source
EcologicalResilience.amplification_metrics — Function
amplification_metrics(c::Community; convention = :published, dt = 0.1)

The six raw columns of community_record that depend on the convention, as a NamedTuple (Amax, tmax, MRinf, MR0, MAmax, Mtmax).

  • :published reproduces Dataset S1. Amax and tmax come from the envelope in the ∞-norm (max_amplification with p = Inf), and the median metrics use published_pulse_covariance.
  • :si follows the definitions of the SI: the spectral norm, and pulses proportional to the surviving species' own biomasses (pulse_covariance).

Requires using FoodWebDynamics.

source
EcologicalResilience.published_pulse_covariance — Function
published_pulse_covariance(c::Community)

The pulse covariance behind the published median metrics (MR0, MRinf, MAmax, Mtmax) of Dataset S1: Diagonal(w.^2) with w = c.B[1:N]. That is the first N entries of the biomass vector over all initial species (extinct ones at zero, in niche order; see FoodWebDynamics' niche_model), set against the N surviving species. The weights agree with pulse_covariance(biomass(c)) only when no species went extinct during assembly. The misalignment reproduces the published data: in communities that kept every species the published median metrics match the aligned weights, with MR0 ≈ −0.76 and no amplification. After extinctions, MR0 drifts towards 0 and about a fifth of communities amplify, as in the published data; aligned weights give neither. Requires using FoodWebDynamics.

source
EcologicalResilience.prepare_metrics — Function
prepare_metrics(raw::DataFrame)

The 27 stability metrics (METRICS) from raw Dataset-S1-style columns, transformed as the authors' prepare_dataframe does so that larger values mean more stability: sign flips, absolute values, normalisation of absumS by N² and of Ext_half by N, and the secondary extinction counts N(1 − Robst). Returns a DataFrame with network (if present), the 27 metrics and N. On the authors' data this equals the publisher's Dataset S1/S2 column by column.

source
EcologicalResilience.read_metrics — Function
read_metrics(path)

Read a dataset of stability metrics and return it in the form of prepare_metrics: either a raw Dataset S1/S2 from the authors' GitHub deposit or one written by community_record (both have the column L1DBRMt_s), or the publisher's Dataset S1/S2 (LaTeX column labels, already transformed).
