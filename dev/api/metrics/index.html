Datasets and conventions

The stability metrics themselves are ResilienceCore's, re-exported here: resilience, reactivity, amplification_envelope, max_amplification, pulse_covariance, the median metrics, stochastic_invariability, the press sensitivities, and the simulated experiments (PerturbationOptions, global_mortality_tolerance, local_mortality_tolerances, press_response, removal_responses, extinction_tolerance). Their documentation is in ResilienceCore.jl. The experiments run on the assembled communities of FoodWebDynamics.jl, which implement ResilienceCore's community interface.

This page documents what is specific to the paper: the Jacobian of an assembled community, the conventions the published Dataset S1 actually used, and the dataset layout.

The community's Jacobian

DominguezGarcia2019.community_jacobian — Function
community_jacobian(c::Community)

The Jacobian of the bioenergetic model at the assembled equilibrium of c, as ResilienceCore's ContinuousJacobian with the surviving species' biomasses as its equilibrium (so that the median metrics' default pulses are proportional to them).

The published conventions

DominguezGarcia2019.published_max_amplification — Function
published_max_amplification(op::ContinuousJacobian; dt = 0.1)

(Amax, tmax) as in Dataset S1: the maximum of the amplification envelope in the ∞-norm (maximum absolute row sum of exp(J t)) on a grid of step dt, but (1.0, 0.0) whenever the reactivity in the spectral norm is not positive. In the published data Amax = 1 exactly when R0 ≤ 0, so the gate uses the 2-norm reactivity R0 even though the envelope uses the ∞-norm. ResilienceCore's max_amplification(op; p = Inf) gates on the ∞-norm reactivity instead, which can differ when R0 ≤ 0 but the ∞-norm logarithmic norm is positive; this helper exists only to keep the published convention.

DominguezGarcia2019.published_pulse_covariance — Function
published_pulse_covariance(c::Community)

The pulse covariance behind the published median metrics (MR0, MRinf, MAmax, Mtmax) of Dataset S1: Diagonal(w.^2) with w = c.B[1:N]. That is the first N entries of the biomass vector over all initial species (extinct ones at zero, in niche order; see FoodWebDynamics' niche_model), set against the N surviving species. The weights agree with pulse_covariance(biomass(c)) (ResilienceCore) only when no species went extinct during assembly. The misalignment reproduces the published data: in communities that kept every species the published median metrics match the aligned weights, with MR0 ≈ −0.76 and no amplification. After extinctions, MR0 drifts towards 0 and about a fifth of communities amplify, as in the published data; aligned weights give neither.

DominguezGarcia2019.PUBLISHED_GLOBAL_PRESS — Constant
PUBLISHED_GLOBAL_PRESS

The absolute increase in every species' per-capita mortality, 0.055, of the global press behind the published RM_p and L1DBRM_p (see published_press_factors).

source
DominguezGarcia2019.published_press_factors — Function
published_press_factors(c::Community)

Mortality multipliers of the global press behind Dataset S1's RM_p and L1DBRM_p: every species' mortality rises by the same absolute amount, dᵢ → dᵢ + 0.055 (PUBLISHED_GLOBAL_PRESS), so the factors are 1 + 0.055/dᵢ. The SI describes a 10% rise (dᵢ → 1.1 dᵢ), which the published local presses follow, but the published global press is about 30 times larger and varies between communities as an absolute rise does. Fitted to Dataset S1, this press reproduces the median RM_p and L1DBRM_p in every richness class, their ratio, the spread of RM_p relative to the summed local responses, and their rank correlation (ρ 0.91–0.95). Why the authors' code applied it is not known.

DominguezGarcia2019.amplification_metrics — Function
amplification_metrics(c::Community; convention = :published, dt = 0.1)

The six raw columns of community_record that depend on the convention, as a NamedTuple (Amax, tmax, MRinf, MR0, MAmax, Mtmax).

  • :published reproduces Dataset S1. Amax and tmax come from the envelope in the ∞-norm (published_max_amplification), and the median metrics use published_pulse_covariance.
  • :si follows the definitions of the SI: the spectral norm (max_amplification of ResilienceCore), and pulses proportional to the surviving species' own biomasses (pulse_covariance).

Datasets

DominguezGarcia2019.RAW_COLUMNS — Constant
RAW_COLUMNS

The 39 data columns of the raw Dataset S1/S2 (after the network identifier), in file order: 28 metric columns, then N, iniN, Nb, Napex, Ncan, Btot, B_IPR and the community's exponents a_i, a_j, h_i, h_j.

METRICS

DominguezGarcia2019.community_record — Function
community_record([rng], c::Community; options = PerturbationOptions(), dt = 0.1,
                 convention = :published)

All raw columns of Dataset S1 (RAW_COLUMNS) for one assembled community, as a NamedTuple. This runs every perturbation experiment, so it is the expensive step. convention selects how Amax, tmax and the four median metrics are computed (see amplification_metrics). :published reproduces Dataset S1, and :si follows the SI's definitions.

The global press (RM_p, L1DBRM_p) depends on convention. :si raises every species' mortality by options.press (10%), as the local presses do. :published raises it by the absolute amount that reproduces Dataset S1 (published_press_factors).

The simulation experiments are those of ResilienceCore (global_mortality_tolerance, press_response, removal_responses, extinction_tolerance, …), run through FoodWebDynamics' implementation of the community interface.

source
DominguezGarcia2019.prepare_metrics — Function
prepare_metrics(raw::DataFrame)

The 27 stability metrics (METRICS) from raw Dataset-S1-style columns, transformed as the authors' prepare_dataframe does so that larger values mean more stability: sign flips, absolute values, normalisation of absumS by N² and of Ext_half by N, and the secondary extinction counts N(1 − Robst). Returns a DataFrame with network (if present), the 27 metrics and N. On the authors' data this equals the publisher's Dataset S1/S2 column by column.

source
DominguezGarcia2019.read_metrics — Function
read_metrics(path)

Read a dataset of stability metrics and return it in the form of prepare_metrics: either a raw Dataset S1/S2 from the authors' GitHub deposit or one written by community_record (both have the column L1DBRMt_s), or the publisher's Dataset S1/S2 (LaTeX column labels, already transformed).
