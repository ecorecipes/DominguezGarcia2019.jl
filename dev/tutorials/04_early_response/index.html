The early response to pulse: median metrics and an indexing artefact

Simon Frost

Overview

Domínguez-García et al. (2019) group 27 stability metrics into three “dimensions” of stability. One of them, the early response to pulse, is built around three median metrics:

  • the median reactivity MR0;
  • the median maximal amplification MAmax;
  • the time at which it is reached, Mtmax.

This vignette shows that MAmax and Mtmax vary between communities, and so can form a group at all, only because of a bookkeeping error in how the median metrics were weighted. The evidence comes first from the published data alone and then from simulations computed both ways.

using EcologicalResilience
using FoodWebDynamics
using CSV, DataFrames, Statistics, Random, Printf
using Plots
data = joinpath(pkgdir(EcologicalResilience), "data")
pub = CSV.read(joinpath(data, "dominguez-garcia2019", "Dataset_S2.csv"), DataFrame)
sim = CSV.read(joinpath(data, "simulated", "ensemble_v4.csv"), DataFrame)
sim = sim[5 .<= sim.N .<= 99, :]
(published = nrow(pub), simulated = nrow(sim))
(published = 9380, simulated = 9744)

Median metrics and their pulse weights

The median metrics average the response of the linearised dynamics, with Jacobian J, over random pulses whose covariance is C (Arnoldi et al. 2018). The SI follows that paper and takes each species’ pulse proportional to its equilibrium biomass, C = diag(B²). The median reactivity is then

\[MR_0 = \frac{\operatorname{Tr}(C J)}{\operatorname{Tr} C}.\]

The published values are reproduced by a different C (see the package documentation of published_pulse_covariance). It takes the biomass vector over all initial species (extinct ones at zero, species in niche order), truncates it to its first N entries, and uses those as the weights of the N survivors. When no species died during assembly the two coincide. After an extinction, survivors receive other species’ biomasses, or zeros.

function community_with_losses(rng, S, minlost)    # first viable draw that lost species
    while true
        c, _ = assemble_community(rng, S)
        c !== nothing && c.initial_richness - richness(c) ≥ minlost && return c
    end
end
c = community_with_losses(Xoshiro(7), 30, 3)
J = jacobian(c.B, c.model)
N = richness(c)
weights = DataFrame(species = findall(c.model.alive), own_biomass = biomass(c),
                    published_weight = c.B[1:N])
filter(r -> r.own_biomass != r.published_weight, weights)   # survivors whose weight is wrong

Evidence from the published data alone

Communities that lost no species during assembly are unaffected by the misalignment. If median amplification were a property of the communities, it would vary smoothly with how many species they lost. Instead it switches on at the first extinction.

lost_class(l) = l == 0 ? "0" : l == 1 ? "1" : l ≤ 4 ? "2–4" : "≥5"
by_lost(df) = combine(groupby(transform(df, [:iniN, :N] => ByRow((i, n) -> lost_class(i - n)) => :lost), :lost),
                      nrow => :communities, :MAmax => (x -> mean(x .> 1 + 1e-12)) => :share_amplifying,
                      :MR0 => median => :median_MR0)
sort(by_lost(pub), :lost)

In Dataset S2, communities that lost no species almost never amplify a median pulse. With one or more extinctions, about a quarter do, regardless of how many species were lost. The median reactivity jumps in the same way.

The same communities, computed both ways

Our ensemble stores every community’s median metrics under both weightings. The raw columns follow the published convention; the *_si columns follow the SI.

si = copy(sim)
for col in (:Amax, :tmax, :MRinf, :MR0, :MAmax, :Mtmax)
    si[!, col] = si[!, Symbol(col, "_si")]
end
lost = sim.iniN .- sim.N
classes = ["0", "1", "2–4", "≥5"]
share(df) = [mean(df.MAmax[lost_class.(df.iniN .- df.N) .== k] .> 1 + 1e-12) for k in classes]
plot(classes, [share(pub), share(sim), share(si)]; marker = :circle, lw = 2,
     label = ["published (Dataset S2)" "ours, published weights" "ours, SI weights"],
     xlabel = "species lost during assembly", ylabel = "share with MAmax > 1", ylim = (0, 0.35),
     legend = :topleft, size = (650, 380))

With the published weighting, our simulations reproduce the switch. With the SI’s weighting, the number of communities amplifying a median pulse falls to 3 out of 9744, so MAmax and Mtmax are effectively constant.

What this does to the stability dimensions

The paper’s groups come from Louvain modularity on the network of metrics, whose edge weights are the absolute Spearman correlations averaged over a size class. A constant metric has no defined correlations, so it cannot belong to any group.

sc = Dict("published" => size_correlations(read_metrics(joinpath(data, "dominguez-garcia2019", "Dataset_S2.csv"))),
          "ours, published weights" => size_correlations(prepare_metrics(sim)),
          "ours, SI weights" => size_correlations(prepare_metrics(si)))
function groups(s, lo, hi)
    R, _ = class_average(s, lo, hi)
    g, _ = modular_groups(metric_network(R); runs = 50, rng = Xoshiro(1))
    return [join(s.labels[g .== k], " ") for k in 1:maximum(g)]
end
for name in ("published", "ours, published weights", "ours, SI weights")
    println(name)
    foreach(x -> println("    ", x), groups(sc[name], 85, 95))
end

In large communities (85–95 species) the published data and our simulations with the published weights give the same three groups. The early-response group holds R0, Amax, tmax, MR0, MAmax and Mtmax. With the SI’s weights, MAmax and Mtmax are isolated, and MR0 joins the sensitivities to press. Of the paper’s three dimensions, distance to threshold and sensitivity to press survive the correction. The early response to pulse reduces to the extremal pulse metrics R0, Amax and tmax.

Caveats

  • The mechanism is inferred. The authors’ simulation code is not public. The truncation reproduces the published distributions and their dependence on species lost, but it is inferred from the data, not read from their code.
  • The published evidence needs no simulator. The switch at the first extinction comes from the published data alone. Only the comparison of groups under the SI’s weighting depends on our reconstruction.
  • Why median pulses rarely amplify here. In these communities, median pulses scaled by biomass are dominated by plants. Plants hold most of the biomass and regulate themselves strongly, so median amplification is rare under the SI’s definition. This is a property of the model family, not a general statement about median amplification.
